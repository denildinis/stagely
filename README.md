# Stagely

## 📌 Sobre o Projecto

Stagely é uma plataforma web para acompanhamento e gestão de estágios curriculares, desenvolvida em equipa no âmbito da Prova de Aptidão Profissional (PAP) do Curso Técnico de Informática do Instituto Politécnico Dom Damião Franklin, no ano lectivo 2025/2026.

O projecto procura centralizar as informações dos estágios, facilitar a atribuição de alunos às empresas e apoiar o acompanhamento e a avaliação do percurso dos estagiários.

---

## 🎯 Objectivo

Melhorar a organização e o acompanhamento dos estágios curriculares, reunindo numa plataforma as informações dos alunos, das empresas, dos estágios e das avaliações.

A proposta visa facilitar o trabalho de supervisão e tornar mais acessível a consulta do progresso dos estagiários.

---

## 📱 Funcionalidades

- Gestão de empresas que recebem estagiários.
- Atribuição de alunos às empresas.
- Acompanhamento dos estágios curriculares.
- Envio de fichas de avaliação em PDF.
- Consulta de indicadores através de painéis de acompanhamento.

---

## 🛠 Tecnologias Utilizadas

- 🎨 **Frontend:** HTML5, CSS3 e JavaScript.
- 🖥 **Backend:** PHP.
- 🗄 **Base de dados:** MySQL.

## 🧰 Pré-requisitos

Para executar o projecto localmente, é necessário um ambiente com **PHP, MySQL e um servidor web**.

### ✔ 1. Git — opcional

Necessário para clonar o repositório. Também podes descarregar o projecto em formato ZIP.

- [Descarregar Git](https://git-scm.com/)

### ✔ 2. Servidor Local

Podes utilizar o **XAMPP**, que inclui Apache, PHP, MariaDB e phpMyAdmin.

- [Descarregar XAMPP](https://www.apachefriends.org/)

### ✔ 3. Editor de Código

- [Visual Studio Code](https://code.visualstudio.com/)

### ✔ 4. Navegador Moderno

Chrome, Edge ou Firefox.

---

## 📥 Como Instalar

1. Clona o repositório:

   ```bash
   git clone https://github.com/denildinis/stagely.git
   ```

2. Coloca a pasta do projecto no directório `htdocs` da instalação do XAMPP.

   Exemplo no Windows:

   ```text
   C:\xampp\htdocs\stagely
   ```

3. No painel do XAMPP, inicia os serviços **Apache** e **MySQL**.

4. Abre o phpMyAdmin:

   ```text
   http://localhost/phpmyadmin
   ```

5. Configura a base de dados de acordo com a estrutura SQL utilizada pelo projecto.

6. Ajusta os dados de ligação à base de dados no ficheiro de configuração correspondente.

> O nome da base de dados, o ficheiro SQL e o caminho da configuração devem corresponder aos utilizados no código.

---

## ⚙️ Como Usar

Depois de configurares o ambiente e a base de dados:

1. Acede ao projecto através do servidor local:

   ```text
   http://localhost/stagely/
   ```

2. Abre a página de entrada da aplicação.
3. Autentica-te com uma conta configurada na base de dados.
4. Explora as funcionalidades disponíveis para o teu perfil.
